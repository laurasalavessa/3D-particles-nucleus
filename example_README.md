Here is an example of data used for the macro; due to limitation of
size, some slices were removed and a spatial crop and subsampling (factor 2.5) was done.  
  
Information about the image:  
Example Image: Primary human keratinocytes (HEK), UVB irradiated 1J/cm2,
that have internalized melanocores for one day.  
Microscope: Laser scanning confocal microscope (Nikon AX) equipped with
motorized stage and a CFI PlanApo Lambda D 60X OIL WD 0,15mm objective,
with numerical aperture of 1,42.  
Pixel size original image: 0.103 µm
Pixel size subsampled image: 0.258 µm
Z-step: 0.22 µm  
Channels: red (keratin-5), green (µH2AX), blue (alpha-tubulin), grey
(brightfield), cyan (DAPI).
